# Manual for administrators

This manual is for users in the role of ***administrator*** who set up and look after camindo CMS: the structure of the contents, websites and languages, users and rights, media processing and the transfer of structures. Installation, updates and server operation (chapters 1 and 12) are usually the task of the ***system administrator***.

If you set up camindo CMS for the first time, the best place to start is [chapter 2 – The concept](./02-concept.md). It explains the ideas on which the system is built and ends with a guide to the first steps.

The daily work with contents – searching, editing, batch processing, export and import – is described in the [manual for editors](../editors/README.md).
