# Editors' manual

This manual is for everyone who maintains content in the backend of camindo CMS – editors,
authors and translators. The work surface is designed so that most steps explain themselves;
this manual clarifies the connections and presents the functions that are easy to overlook.

## Contents

1. [Key terms](./01-key-terms.md) – frontend and backend, content area, record, input field,
   status, template
2. [Signing in and out](./02-sign-in.md) – sign-in, sign-in code, language, date format,
   time zone
3. [The work surface](./03-work-surface.md) – start page, layers, keyboard operation,
   background processes, messages, AI assistant, personal settings, widgets
4. [Finding content](./04-finding-content.md) – folder tree, record list, search form,
   search operators, cross-area search
5. [Editing records](./05-editing-records.md) – creating, editing, copying, moving, deleting,
   trash; input fields, relations, files, publication, edit lock
6. [Multilingual content](./06-multilingual-content.md) – language versions, translating,
   finding missing translations
7. [Batch processing](./07-batch-processing.md) – change, move or delete many records at once
8. [Export and import](./08-export-import.md) – CSV for Excel, Word files for translators,
   XML backups, re-import
9. [Frontend editing and preview](./09-frontend-editing.md) – editing content directly on the
   website
10. [Reviewing contributions from website visitors](./10-visitor-contributions.md) – reviewing
    comments, profiles and other contributions, personal data export, deleting profiles
