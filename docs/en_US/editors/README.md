# Editors' manual

This manual is for everyone who maintains content in the backend of camindo CMS – editors,
authors and translators. The work surface is designed so that most steps explain themselves;
this manual clarifies the connections and presents the functions that are easy to overlook.

## At a glance: what makes camindo CMS special for editors

- ***One interface for everything.*** Whether articles, products, appointments or images – every
  content area has its own, suitable input form, search form and list. Operation is the same
  everywhere. Training new colleagues takes minutes, not days. A cross-area search lets you find
  any content managed in the CMS.
- ***Many records at once.*** With [batch processing](./07-batch-processing.md) you change a field
  in hundreds of records with one click. Via the [CSV export](./08-export-import.md#editing-content-in-excel)
  you edit content in Excel and load it back in.
- ***Nothing gets lost.*** You always work on a working copy; the website only shows your changes
  after you save. The [edit lock](./05-editing-records.md#edit-lock) prevents two people from editing
  the same record at once. Deleted content goes to the trash first and can be restored.
- ***Translating without CMS access.*** The [DOCX export](./08-export-import.md#translating-with-word-docx)
  creates a Word file for the translation agency; the translated file is simply imported again.
- ***Much can be automated.*** Talk to your template programmer if you want to get rid of tedious
  tasks – the functionality is already in the system: sending regular overviews by email, automatic
  booking confirmations as PDF, archiving old entries, and much more.
- ***Help from artificial intelligence.*** The add-on module “AI assistant” is there to help you: it
  carries out changes on your behalf or explains functions to you. If the assistant does not have the
  necessary rights itself, it can open the appropriate input form in the backend for you.
