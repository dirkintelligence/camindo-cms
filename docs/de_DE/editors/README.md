# Handbuch für Anwender

Dieses Handbuch richtet sich an alle, die im Backend von camindo CMS Inhalte pflegen –
Redakteure, Autoren, Übersetzer. Die Arbeitsoberfläche ist so gestaltet, dass sich
die meisten Schritte von selbst erklären; das Handbuch erläutert die Zusammenhänge
und stellt die Funktionen vor, die man leicht übersieht.

## Inhalt

1. [Wichtige Begriffe](./01-begriffe.md) – Frontend und Backend, Inhaltsbereich,
   Datensatz, Eingabefeld, Status, Template
2. [Anmelden und Abmelden](./02-anmeldung.md) – Anmeldung, Anmelde-Code,
   Sprache, Datumsformat, Zeitzone
3. [Die Arbeitsoberfläche](./03-arbeitsoberflaeche.md) – Startseite, Ebenen,
   Bedienung mit der Tastatur, Hintergrundprozesse, Nachrichten, KI-Assistent,
   persönliche Einstellungen, Widgets
4. [Inhalte finden](./04-inhalte-finden.md) – Bereichsbaum, Datensatzliste,
   Suchmaske, Suchoperatoren, bereichsübergreifende Suche
5. [Datensätze bearbeiten](./05-datensaetze-bearbeiten.md) – Anlegen, Bearbeiten,
   Kopieren, Verschieben, Löschen, Papierkorb; Eingabefelder, Verknüpfungen,
   Dateien, Veröffentlichung, Bearbeitungssperre
6. [Mehrsprachige Inhalte](./06-mehrsprachigkeit.md) – Sprachversionen,
   Übersetzen, fehlende Übersetzungen finden
7. [Stapelverarbeitung](./07-stapelverarbeitung.md) – viele Datensätze auf einmal
   ändern, verschieben oder löschen
8. [Export und Import](./08-export-import.md) – CSV für Excel, Word-Dateien für
   Übersetzer, XML-Sicherungen, Re-Import
9. [Frontend-Editing und Vorschau](./09-frontend-editing.md) – Inhalte direkt von
   der Website aus bearbeiten
10. [Beiträge von Website-Besuchern prüfen](./10-community.md) – Prüfen von
    Kommentaren, Profilen und anderen Beiträgen, Datenexport personenbezogener Daten,
    Profile löschen
