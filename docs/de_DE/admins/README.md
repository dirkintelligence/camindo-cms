# Handbuch für Administratoren

Dieses Handbuch richtet sich an Benutzer in der Rolle des ***Administrators***, die
camindo CMS einrichten und betreuen: die Struktur der Inhalte, Websites und Sprachen,
Benutzer und Rechte, Medienverarbeitung und die Übertragung von Strukturen. Installation,
Updates und Serverbetrieb (Kapitel 1 und 12) sind meist Sache des
***Systemadministrators***.

Wer camindo CMS zum ersten Mal einrichtet, liest am besten zuerst
[Kapitel 2 – Das Konzept](./02-konzept.md). Es erklärt die Ideen, auf denen das
System aufbaut, und endet mit einem Leitfaden für die ersten Schritte.

Die tägliche Arbeit mit Inhalten – Suchen, Bearbeiten, Stapelverarbeitung, Export
und Import – beschreibt das [Handbuch für Anwender](../editors/README.md).
