# Extension IconPicker (Icon-Auswahl)

Core-Extension für einzeilige Felder aller Feldtypen, die den Namen eines
***Material-Symbols*** speichern (z. B. `menu_book`). Standard für das Icon eines
Inhaltsbereichs (Modul „Struktur“ → Bereich → Icon). Immer verfügbar, keine
Installation nötig, keine Einstellungen.

## Bedienung

Rechts neben dem Feld zeigt eine ***Vorschau*** das eingetragene Icon; bleibt sie leer,
ist der Name unbekannt oder das Feld leer. Die Schaltfläche ![add](../../_/add.svg) öffnet das
Auswahlfenster:

- Ohne Suchbegriff zeigt das Fenster die Icons einer ***Kategorie*** (Aktionen, Hinweise,
  Audio & Video, Kommunikation, Inhalt, Geräte, Editor, Dateien, Hardware, Zuhause,
  Bilder, Karten, Navigation, Benachrichtigungen, Orte, Suche, Soziales, Schalter);
  ![chevron_left](../../_/chevron_left.svg) ![chevron_right](../../_/chevron_right.svg)
  blättern durch die Kategorien.
- Das ***Suchfeld*** durchsucht alle Icons nach Name und ***Schlagwörtern*** (englisch,
  aus dem Suchindex von Google Fonts, z. B. `book`, `calendar`, `person`). Mehrere
  Begriffe müssen alle vorkommen. Die Eingabetaste übernimmt den Suchbegriff ins Feld:
  einen exakten Icon-Namen, sonst den einzigen Treffer, sonst den Text selbst
  (Leerzeichen werden zu `_`).
- Ein Klick auf ein Icon schreibt seinen Namen ins Feld und schließt das Fenster.
  ![block](../../_/block.svg) „Kein Icon“ leert das Feld.
- ![close](../../_/close.svg), die Esc-Taste oder ein Klick außerhalb schließen das
  Fenster ohne Änderung.

Der Name lässt sich auch direkt eintippen; die Vorschau folgt beim Tippen. Die Namen
und alle Icons stehen unter [fonts.google.com/icons](https://fonts.google.com/icons)
(Stil „Material Symbols Outlined“).
